# 常见问题

## 只有一边有声音

1. 停止 DualSpeaker，确认两台音响在 Windows 中分别能独立播放。
2. 检查左右输出是否选成了同一台，设备是否断线或静音，设备音量和软件音量是否为 0。
3. 把播放器自己的输出选择改为“系统默认”，避免绕过本程序直接输出到某台蓝牙音响。
4. 重新开始播放。爱奇艺相关兼容处理只在 DualSpeaker 播放期间启用。

如果仍失败，请记录设备型号、Windows 版本、播放器版本及“运行日志”中的错误。其他电脑不一定与开发环境的故障成因相同。

## 笔记本也在发声

确认“电脑音源”选的是内置声卡等独立端点，并检查程序的静音保护状态。原播放器应使用系统默认输出。不要手动把电脑音源切换到左、右输出音响之一。

## Windows 显示静音，但两台音响有声音

这是预期行为。程序把原始默认输出静音以免笔记本重复出声，再将捕获的音频分发到两台音响。运行期间用 DualSpeaker 的总音量、浮窗或标准音量键调节。

## 键盘旋钮太慢，或者按下没有静音

在“设备与校准”页修改旋钮步长。程序处理标准 Windows 音量加、音量减和静音事件。键盘如果把按下旋钮映射成播放暂停、厂商专用命令或其他快捷键，需要先在键盘驱动中修改映射；程序不保证支持所有旋钮协议。

## 两台之间有回声，或者看电影声音落后

先在正常听音位置重新自动校准。左右时间差和整体音画延迟是两个问题：校准只能对齐两台音响的到达时间，不能去掉蓝牙本身的延迟。支持音画偏移的播放器可以单独调整；增加左右延迟不能让整体声音提前。

## 自动校准失败

确认 Windows 允许桌面应用使用麦克风，选择正确输入设备，靠近日常听音位置，适当提高音响音量并减小环境噪音。麦克风需要能听见两台设备。校准失败不会被当作已通过，可以继续播放并手动调整。

## 关闭后电脑还是没有声音

正常退出和异常恢复助手会尝试恢复启动前的声音设置。若未恢复，先确认 DualSpeaker 已经关闭，再运行便携目录中的 `recover-audio.cmd`。不要在另一个播放实例运行时使用恢复命令。如果设备已经断开，仍可能需要到 Windows 声音设置中手动选择可用输出。

## 下载后能否只保留一个 EXE

不能。需要保留 NAudio DLL、`DualSpeaker.exe.config` 与 `fonts/`。程序目录必须可写，才能保存设备选择、恢复记录和日志。

## 是否会录音或上传声音

普通播放不打开麦克风。自动或手动校准会短时录音并保存到本地 `diagnostics/`；可以关闭启动自动校准并自行删除录音。应用没有上传或遥测功能。反馈问题时不要默认附带整个程序目录。

## 可以用三台音响、Windows 10 或有线设备吗

当前界面和音频引擎针对两路输出；Windows 11 x64 是已验证目标。核心输出使用 Windows 音频端点，有线设备可能可用，但并未系统验证；Windows 10、ARM64 原生构建和更多输出不在当前支持范围内。
