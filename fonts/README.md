# Bundled pixel font

Fusion Pixel Font, 12px proportional Simplified Chinese (`zh_hans`).

- Upstream: https://github.com/TakWolf/fusion-pixel-font
- Release: 2026.10.16
- Original archive: `fusion-pixel-font-12px-proportional-ttf-v2026.10.16.zip`
- Bundled file: `fusion-pixel-12px-proportional-zh_hans.ttf`, unmodified.
- License: SIL Open Font License 1.1, reproduced in `OFL.txt`; upstream component notices are retained in `LICENSES/`.

The application loads this font privately for its own process through GDI+ and GDI. It does not install the font globally or modify Windows font settings. Keep this directory next to the executable when copying the application.
